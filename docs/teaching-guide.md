# AI赋能医学统计与科研实战
## 16学时授课执行与方法学补充

配套：119页《16学时完整PPT_V3_案例顶刊实战版》。本册根据原PPT实际页码编写，新增课堂执行细节，不替代原课件、学生数据或教师R脚本。日期：2026年9月10日。

## 一、授课安排

按每学时45分钟、共720分钟设计，课间休息另计。四次课各4学时。若学校采用50分钟学时，每节增加5分钟个别反馈。数据D01—D07均按原课件定义使用，不重新生成，以免学生数据与教师答案失配。

每节建议：5分钟独立判断、10分钟概念讲解、18分钟操作或拆解、8分钟交叉核验、4分钟出口题。第16学时使用独立答辩安排。教师无需逐页朗读，资源页92—111用于课前阅读和按需调用。

结业项目从第一次课即发布，第二次课后提交分析计划，第三次课后交代码初稿，第四次课前完成图表和论文拆解。第16学时用于答辩与修订，不再现场从零开展完整项目。

## 二、逐学时教学脚本

| 学时 / V3页码 | 学生现场任务 | 教师追问及答案要点 | 本节验收 |
|---|---|---|---|
| 1 / 9—13 | 用D01写一个主要问题及两个不同的次要问题。主要问题写明人群、治疗比较、12周结局及效应指标。 | “你要估计组间疗效，还是描述某组变化？”主要疗效问题需要组间比较，不能只看各组前后P值。 | 一句话主要目的，明确主结局；不以显著性选择问题。 |
| 2 / 14—18 | 对连续结局、二分类结局、时间结局各提出一种分析方案，并注明独立或配对结构。 | “同一个人多次记录为何不能当作独立患者？”观测相关性影响标准误和分析单位。 | 每种方法均附适用条件，而非只列软件名称。 |
| 3 / 19—23 | 为D05或D06填写8列字典：变量名、含义、类型、单位、编码、参照组、缺失码、角色。 | “Stage=1/2/3意味着等间距吗？”编码不能自动证明等间距；分类或趋势建模需说明假设。 | Status=1/0解释明确；ID用于链接，不作普通数值预测变量。 |
| 4 / 24—28 | 对D02建立疑点清单，区分可核对的单位问题、重复观测、真实极值和无法确认问题。 | “同一个ID出现两次就删除吗？”可能是重复导入，也可能是合理的不同访视，先核查记录粒度。 | 原始文件保留；每项处理有依据；无法确认的值不猜填。 |
| 5 / 30—34 | 用D03比较住院天数的均值、中位数、四分位数和图形，制作5个变量的描述表。 | “中位数更稳健，是否就不能报告均值？”看研究目标；平均资源消耗可能仍需均值及适当不确定性估计。 | 表内有单位、n和分母、缺失数，解释统计量选择。 |
| 6 / 35—39 | 用已有D01分析结果写4句解释：比较方向、差值、区间、不确定性与医学含义。 | “P>0.05能说明两组等效吗？”不能；区间可能仍容许有意义的差异，等效问题需独立设计。 | 不把95%CI写成95%的患者范围；不把P值写成假设为真的概率。 |
| 7 / 40—44 | 对D01分别回答组间差异与同一患者前后变化，比较两种分析的研究问题。 | “A组显著、B组不显著就说明A优于B吗？”不能，需直接检验组间效应差异。 | 报告配对/独立结构、分析人数、效应方向；将组内变化与疗效比较分开。 |
| 8 / 45—50 | 用D04预先写出总体问题和要比较的组对，再运行总体及多重比较分析。 | “总体显著意味着任意两组都不同吗？”不意味着；预设对比也不必一律以总体显著为前提。 | 明确比较族、校正方式和各组对效应区间。 |
| 9 / 51—55 | 用D05生成2×2表，手工计算各组风险、风险差、RR和OR，再核对软件。 | “20/100对10/100，RR和OR是多少？”RR=2，OR=2.25，风险差为10个百分点。 | 给出事件数和总人数；OR、RR和百分点不混用。 |
| 10 / 56—60 | 用D03先画BMI与HbA1c散点图，再比较相关系数和回归斜率的含义。 | “回归系数的单位是什么？”结局单位/暴露单位；相关系数无量纲。 | 解释关系形态和影响点，避免用横断面关联证明因果。 |
| 11 / 61—65 | 用D05先检查治疗组间Stage分布，再在相同分析样本上比较粗模型和调整模型。 | “OR变化都能归于混杂吗？”不能，还应检查样本变化、编码、模型设定及OR不可折叠性。 | 给出协变量选择依据、参照组和两模型n；调整后仍保留观察性解释边界。 |
| 12 / 66—70 | 用D06说明时间起点和删失，读KM图及风险集，检查Cox模型诊断。 | “PH检验不显著就证明PH成立吗？”不能，检验效能有限，需结合残差图、时间效应和研究背景。 | 给出诊断证据和单一HR的解释限制；不为追求显著而挑时间分界。 |
| 13 / 72—76 | 用D07在Train确定判阳方向及阈值，锁定后应用Test，交混淆矩阵。 | “Test表现差能否再调阈值？”再调后它不再是独立最终测试集，需要新的独立评估。 | 阈值及大于/大于等于规则明确，Test不参与选阈值或预处理拟合。 |
| 14 / 77—81 | 从空白R会话重跑一组作业，核对文件、样本数、编码、模型和结论。 | “两个AI给同样答案是否完成验证？”没有，必须检查实际计算、输入和假设，两个输出可能共享错误。 | 可重跑脚本、sessionInfo、一个手工验算、至少一项模型诊断。 |
| 15 / 82—86 | 对本组项目生成一张表、一幅图和100—150字结果段，与另一组互审。 | “正文和图表里的分析n为什么不同？”需明确缺失、模型纳入条件和分析集，不可默默改变分母。 | 图表可独立理解，单位和区间齐全，正文数值与代码一致。 |
| 16 / 87—90、112 | 使用课前完成的项目进行8分钟汇报、4分钟追问，教师随机问个人。 | “哪个结论最依赖你的假设？删去这条假设后还成立吗？”回答应回到设计、数据和敏感性分析。 | 提交修订说明；区分独立完成部分、AI协助部分及未解决问题。 |

第16学时45分钟可安排3组，每组12分钟，另留9分钟总结。超过3组采用并行小组评议和教师抽查，或将部分汇报移至课前录屏，不能把所有组的12分钟报告硬塞进一学时。

## 三、V3配套方法学勘误与讲授限定

以下为教师补充说明，原PPT尚未改写。课堂遇到对应页时使用本表。

| V3位置 | 需要补充或收窄的表述 | 建议讲授版本 |
|---|---|---|
| 第4、109—111页 | 将报告规范称为“真实论文拆解9—11”容易与实证研究混淆。 | 8篇研究论文加3项报告规范，分别用于研究拆解和报告完整性检查。 |
| 第8、29页 | 阶段概览与实际学时不完全对应，第29页包含实际第9学时的χ²。 | 第1—4学时为问题、设计、变量与质控；第5—8学时为描述、推断、两组和多组比较。 |
| 第16页 | “所有方法选择都从结局变量开始”过于绝对。 | 先确定研究问题、设计、分析单位与目标效应，再结合结局类型选择方法。 |
| 第21页 | “ID绝不入模”没有区分普通协变量与结构标识。 | ID不作为普通数值协变量；患者或中心ID可用于识别重复测量、聚类或随机效应结构。 |
| 第37页 | “主要结局Week12_SBP或Change_SBP”易造成事后选择。 | 课前在SAP确定主要结局与主分析，另一种作为补充，不按P值择优。 |
| 第41—44页 | 偏态不自动意味着必须改用秩检验。 | 根据目标效应、样本结构、离群和分布选择。Mann–Whitney一般不直接检验中位数差，需额外分布假设才能作相应解释。 |
| 第43页 | 分组内前后显著性不能支持组间疗效差异。 | 组内分析用于解释变化，疗效结论使用直接组间比较或适当基线调整模型。 |
| 第45—50页 | 事后比较与预设对比应区分。 | 先确定比较问题及错误率控制方案，不能将“总体显著”教成所有对比的普遍前置条件。 |
| 第61—65页 | 不能把粗OR与调整OR变化单独当作混杂证明。 | 比较同一样本，检查编码，结合时间顺序和专业知识判断混杂，并讨论OR不可折叠性。 |
| 第68、97页 | “cox.zph应提示问题”像确定性标准答案。 | 数据设计含时间变化效应，但一次样本的检验结果不保证显著。评分看诊断及解释，不看是否得到指定P值。 |
| 第69页 | KM交叉不能单独定论所有PH问题。 | 结合模型残差、时间交互及风险集信息；交叉可作为提示，不能替代模型诊断。 |
| 第76页 | Youden阈值不自动等于临床最佳阈值。 | 它是课堂演示准则；实际阈值还受漏诊代价、误诊代价及资源约束影响。 |
| 第88页 | 用合成数据“复刻论文”可能被误解为复现原论文数值。 | 用合成数据复现同类分析流程与图表结构，不声称复现原论文效应估计。 |
| 第89、112页 | 两种汇报时长不一致，且课内任务过量。 | 统一8分钟汇报加4分钟追问，完整分析与8页拆解报告在课前完成。 |

本册未重新运行D01—D07或核查8篇论文全文，因此不新增这些数据的数值答案，不将原课件的预期结果当作本轮已验证计算。

统一Prompt：请依据已提交的SAP分析所附教学数据。先核对变量名、编码、单位、分析单位及样本数。如信息不足，明确列出缺口，不猜测。生成可从空白会话执行的R脚本，保留原始数据。报告实际分析人数、效应量及区间，并执行与模型对应的诊断。所有数值必须来自真实运行，未运行时明确标注。最后核对表、图、正文的一致性，并列出结论依赖的假设。

### C. 论文拆解证据表

沿用V3第100—107页的论文清单，每组选择一篇。必须查原文及可获得的补充材料，不能只凭摘要或AI总结作答。

| 拆解项目 | 必填证据 |
|---|---|
| 研究问题与设计 | 用自己的话写明，附Methods节名或页码。 |
| 人群、分析集及主要结局 | 写明纳入、随机/非随机、结局时间窗和分析集。 |
| 目标效应与主模型 | 解释为何使用该指标，写清参照与单位。 |
| 缺失与模型诊断 | 原文如何处理；未找到就写“所查材料未报告”。 |
| 一张主要表或图 | 指定表图编号，解释分母、效应值、区间及其局限。 |
| 多重比较与亚组 | 区分预设、探索性及交互检验，避免比较两组P值大小。 |
| 推断边界 | 指出一项设计限制和一项不能据此作出的结论。 |
| 合成数据迁移 | 指出D01—D07中哪一数据可练同类方法，以及不能复现什么。 |

报告规范用于核查报告完整性，不能因为条目齐全就认定研究无偏。原文未提供信息时，学生不得替作者编写答案。

## 五、评分与补救

保留V3第116页权重：知识闯关15%、学生反讲15%、AI统计作业20%、论文拆解20%、结业项目30%。

结业项目内部按100分评分，再乘30%计入课程总分：问题与SAP20分；数据和分析集15分；方法与诊断25分；可复现代码15分；表图与解释15分；个人答辩10分。每项完整且有证据得满分，部分完成得约一半，缺失或根本错误不得该项分。

必须修订的问题：把测试集用于调参后仍称独立验证、颠倒结局编码、用组内显著性替代组间效应、把OR解释成RR、删除所有删失者、伪造运行结果。首次提交发现问题后允许有记录地修订，不应奖励碰巧得到预期显著性。

薄弱点补救对应：方法选择错误回第2学时；分母/编码错误回第3—4学时；只讲P值回第6学时；结构错误回第7学时；混杂与因果越界回第11学时；HR解释错误回第12学时；泄漏回第13学时。复测要求换一道等价问题并解释理由。

## 六、开课前准备

- 按现有资源包实际目录分发学生CSV、数据字典和Prompt；隐藏机关与教师答案暂不分发。
- 每组课前在本机读取一个CSV并运行最小R脚本，避免把整节课用于环境安装。
- 教师提前在空白会话运行原教师脚本，确认包依赖、文件路径及结果与学生版数据一致。
- 第一课公布结业任务与分组，角色在四次课间轮换，个人答辩采用随机提问。
- 将本册方法学补充与V3一起备课；本轮交付不代表原PPT已经完成版式重排或数据脚本重验。
