# 学习进步记录

自此版本起，打炮与知识点测试逐题保存到Sites D1数据库。服务端仅使用平台转发的登录用户ID划分记录，不接收客户端指定记录所属者。网页关闭、重新登录后通过账号读取；同一站点中用户相互隔离。

每轮记录范围、练习类型、开始时间、计划题数、实际题目、是否正确及游戏加分。当前轮每答一题就更新快照；相同轮次ID幂等保存，较短旧快照不能覆盖已有较长记录。网络失败时保留按账号区分的临时待同步草稿，成功后删除；不以浏览器草稿替代云端记录。页面明确显示同步失败并提供重试。

正确率=答对数/实际已答数，按整轮、模块或知识点重新计算，不平均各部分百分数。游戏分保留原有速度与连击奖励；知识点测试不虚构游戏分。曲线标出未完成轮次，可按练习类型筛选，明细列出分母、范围和状态。仅展示真实存在的记录；没有数据时显示空态，一次练习显示一个点，曲线最多显示最近30次，明细保留全部。

旧版没有可可靠还原的逐轮分数，不回填虚构成绩。旧版其他学习档案仍维持原实现，新增账号历史仅覆盖打炮和知识点测试，不声称全部课程档案已云同步。当前站点访问范围保持不变，尚未开放学生访问。

新增数据表由Drizzle迁移创建；不在请求中自动建表。记录属于练习反馈，前端计分并不是防作弊或标准化能力考试系统。题目难度尚未校准，不能由不同范围的原始分数变化推断能力等级。
