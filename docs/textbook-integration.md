# 教材答疑接入说明

已接入用户上传的《卫生统计学》Markdown（方积乾主编，文件前言对应第7版）。保留原始文件于 `textbook/source.md`，按正文识别20章，共生成1,003个引用段落。正文位置以原始Markdown行号标注，不将行号当作书本页码。重建命令：`python scripts/textbook/build.py`，随后运行项目构建。

## 学生入口

- 导航栏与作战大厅的“教材答疑”：`/textbook/`。
- 每学时理论学习区的“向教材提问”：预填当前学时问题，由学生提交。
- 提问支持全部章节或指定章节；可继续询问适用条件、教材例题，展开原文及来源位置。
- 常见问题使用逐项绑定教材段落的简明解读，其他问题返回全文检索的相关原文摘录。未启动本地模型时不是大模型生成回答；启动本地Ollama后可用Qwen等中国开源模型基于段落生成解读，仍不自动执行统计计算。
- 无需外部API密钥；问答内容在当前页面会话内存中保留，刷新即清空，检索模式不上传学习问题；模型模式仅将问题及引用段落发送到自建模型服务。现有学习进度保存机制保持不变。
- 静态版在阿里云Nginx或GitHub Pages上使用相同答疑功能。首次须正常读取教材资源；离线可用性依赖浏览器成功缓存，不能保证首次离线使用。

## 程序接入接口（Sites Worker版）

`GET /api/textbook` 返回教材目录与来源元数据。

`POST /api/textbook/ask`，Content-Type 为 application/json：

```json
{
  "question": "Cox回归有什么前提条件？",
  "chapterId": "ch19"
}
```

响应包含 `status`、`mode`、`explanation`、`sources`、`context`、`suggestions`。引用包含稳定段落ID、章节、小节、原始行号、摘录及可展开正文。继续提问时把上次返回的 `context` 原样传回：

```json
{
  "question": "用教材例题说明一下",
  "context": {"question": "Cox回归有什么前提条件？", "chapterId": "ch19"},
  "chapterId": "ch19"
}
```

问题限制800字，请求体限制12KB。Sites接口不记录问题、不调用外部模型；拒绝跨来源浏览器POST。本地Node服务提供同路径的开源模型问答。静态版浏览器直接调用同一检索引擎；若检测到同源本地模型服务，则通过同源接口调用模型。

## 范围及质量边界

问答基于上传文件的正文20章。目录中的重复条目和章编号缺失已按正文标题修复；超长OCR统计用表以及随书光盘内容不参与自动答疑。原始Markdown原样保留，SHA-256记录在清单和导入报告中。正文中的HTML转换成文本，外链插图不自动加载，避免执行教材中混入的代码。

检索采用中文双字索引、英文术语及常见同义词、章节和小节排序；不是语义大模型。教材外内容和弱匹配提示未找到依据。开放式或复杂多条件问题可能只返回相关段落，需要教师核对。公式保留源LaTeX文本，可能存在OCR误差；本书旧版的方法与例题不能冒充当前指南。

验证：`node tests/textbook.mjs`（需先构建）。覆盖来源哈希、20章定位、常见提问与追问、章节过滤、教材外问题、接口校验、静态入口及原有进度接口隔离。

## 免费本地模型

详见源码中的 `deploy/LOCAL-MODEL.md`。默认Qwen3-4B-Instruct-2507量化版；模型可替换为已下载的本地Qwen或DeepSeek-R1。仅支持本机或内网Ollama地址，禁止cloud标签，不存在收费API自动回退。`/api/textbook/status`报告实际模型连接状态。
