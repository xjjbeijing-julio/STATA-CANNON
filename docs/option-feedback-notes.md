- 默认采用浅蓝背景、白色阅读卡片和深色正文。打炮场景保留原操作与动画，选项和答题解析采用明亮阅读面板。
- 为833道练习题和24道课程挑战的3428个选项提供解释。所有错误选项显示具体错误原因，学生所选项另行标记。
